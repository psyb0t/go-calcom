# go-calcom

Unofficial Go client for Cal.com API v2, generated from the public OpenAPI document in the Cal.com repository. To use the client from an agent, read [.agents/skills/go-calcom/SKILL.md](.agents/skills/go-calcom/SKILL.md); this file covers changing the code.

## Architecture

One generated package, `calcom`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh` downloads `https://raw.githubusercontent.com/calcom/cal.com/main/docs/api-reference/v2/openapi.json` to `api/openapi.json`. `scripts/patch-spec.sh` gives duplicate calendar event operation IDs distinct names in `api/openapi.patched.json`. oapi-codegen uses `config.yaml` to generate `client.gen.go`. Every route is retained.

## Stack

- Go 1.26.9.
- oapi-codegen, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, lint and security scan scripts.
- `api/`: the downloaded spec, gitignored.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The source is titled `Cal.diy API v2`, spec version `1.0.0`, OpenAPI 3.0.0. Coverage follows that document.
- The spec has no server URL. Callers pass `https://api.cal.com` or another deployment as the server. Paths already contain `/v2`; do not append it to the base URL.
- Auth is described as header parameters rather than a security scheme. Set Bearer auth in a request editor and populate required `Authorization` parameter fields.
- Many endpoints require `cal-api-version`. Set the endpoint's documented version explicitly; schema defaults do not populate generated Go fields.
- Keep the `number` to `float64` mapping in `config.yaml`.
- Reassignment response `data` is an open object because the upstream schema references itself and omits its described alternatives. Preserve unknown fields until the provider supplies the missing schemas.
- Generated method names contain controller names and endpoint versions. Read signatures before writing examples.
- `make generate` downloads the current spec. Review the generated diff after regeneration.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
